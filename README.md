# Next.js Portfolio Practice

A mini portfolio project built to practice Next.js fundamentals — 
specifically folder-based routing and project structure.


## What I Practiced

- Next.js App Router folder structure
- File-based routing (`/about`, `/projects`, `/contact`)
- Dynamic routes (`/projects/[id]`)
- Layouts and shared components
- `usePathname` for active nav links
- Data-driven UI with reusable components


## Tech Used

- Next.js 15
- React
- CSS

## Purpose

This is a learning project — not a production app.
Built to understand how Next.js routing and structure works
before moving to larger projects.
